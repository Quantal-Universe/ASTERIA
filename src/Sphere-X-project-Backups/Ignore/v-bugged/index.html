SPHEREx measured wavelength samples

Calibrated target-pixel surface brightness · detector arrays D1–D6

Select a target, then load its available SPHEREx measurements.

Loads up to 17 recent products per detector (up to 102 samples), trying the selected release first and the other QR2/QR3 release if it has no coverage. This is a quick-look subset, not a complete 102-band source extraction. Each point is the calibrated pixel at the selected coordinate for that exposure date (Gaia proper motion applied when available), in MJy/sr; it is not PSF-extracted point-source photometry. Error bars use archive variance. Flagged pixels are hollow and samples are shown individually, not combined. Wavelength and bandwidth come from the detector WCS lookup.
